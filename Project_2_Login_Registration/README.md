## Security Note

This project was developed for **educational and internship purposes** to demonstrate C++ file handling and basic authentication concepts.

The credentials are stored in a local text file for learning purposes. In a real-world application, passwords should never be stored as plain text. Secure password hashing and proper authentication mechanisms should be used.

The `student.txt` file should not be uploaded to GitHub because it may contain user credentials.
